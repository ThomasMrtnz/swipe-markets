# Swipe Markets

Petite appli web (installable sur l'écran d'accueil) pour trier d'un geste les offres d'une veille emploi :
à droite pour postuler, à gauche pour passer, vers le haut pour plus tard.

Ce dépôt ne contient que le code de l'appli, publié sur GitHub Pages. Aucune donnée : la liste des offres
est lue dans un dépôt privé avec un jeton GitHub saisi sur le téléphone, et les choix y sont renvoyés.

Le code source de référence se trouve dans le dossier `app/` du dépôt privé de la veille.
